# frontend-plugin-notifications

Hyper Academy’s Ulmo-compatible fork of the Open edX notification-tray plugin.
It is installed into MFEs by `tutor-hyper-live-sessions` and retains the upstream
plugin API.

## Client additions

- Learner-friendly “Live sessions” application tab
- Live-session event icons and states
- Preservation of API field names such as `application_id`
- Tests covering the live-session notification mappings
